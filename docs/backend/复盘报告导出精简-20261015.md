## 验收后的本机环境故障

最终服务检查时 Docker 引擎失联，8000/8080 均超时；宿主机 C 盘可用空间为 0。验收镜像安装前未检查宿主机余量，增加了磁盘压力。Docker Desktop 状态仍显示 running，但后端日志持续报告到虚拟机 `192.168.65.7:2376` 无路由，Docker 管理命令无法正常返回。

尝试删除本次临时渲染镜像 `contest-ops-report-qa:local` 时引擎返回 HTTP 500，未确认删除成功。将 61 个已轮转、十分钟内未写入的 Docker 日志原样转存至 `.local/docker-log-archive-20261015/`，释放约 62 MB，未改业务数据；C 盘仍仅余约 53 MB，引擎未自动恢复。已询问用户先腾出 C 盘空间并授权重启 Docker Desktop，因为重启影响本机其他 Docker 项目。恢复服务后才能再次确认在线健康及清理临时验收镜像。
