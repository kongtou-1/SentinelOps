# Agent 诊断链路修复

本次修复服务监测证据校验、会话采用后的回放轨迹和默认只读能力约束三处已确认缺陷。保持单 Agent、PostgreSQL 队列及原审批执行边界；长会话摘要、公平调度和统一运行版本清单属于后续设计增强，不混入本次修复。

## 服务监测证据

统一通过事故关联资产计算允许 ID，包含服务器、容器、LLM Endpoint 和 ServiceMonitor。取证、候选提交、跨轮继承、完成校验和人工采用使用相同范围；无关服务监测仍被拒绝。保留已有源码快照、数据库冻结范围和错误证据过滤。

## 采用与案例回放

工具完成事件保存经过校验和脱敏的实际参数，数据库查询使用既有脱敏 SQL 摘要。采用时保留已引用观测，以及必要的事故上下文、Skill 目录和加载记录；从本会话截至该轮的工具记录中关联对应参数，支持采用跨轮保留的服务指标。

私有聊天、SDK 原始提示词、候选提交参数及未采用输出不进入正式诊断或案例。已采用记录仍独立于后续会话变化和会话删除，不修改原历史诊断。

Admin 收录案例前通过 `/api/v1/analyses/{id}/evaluation-preview` 预览实际将冻结的工具记录，确认脱敏后保存版本。前端提交预览哈希，保存时重新计算；不一致返回 409。预览沿用 `knowledge:manage`，不接受私有运行 ID。旧轨迹缺少必要参数时记录 `arguments_unavailable` 缺口，不猜测参数、不访问生产补取，也不重写旧案例。

## 只读能力

新诊断运行在配置中冻结 `diagnosis_mode=read_only`。单次诊断、对话和当前模型回放的网关均不开放 `propose_action_skill`；后端结果校验拒绝非空 `proposal`，不依赖 Skill 文本或模型遵循提示词。模拟 Provider 按实际工具清单返回结果。

未包含该模式的历史诊断按原语义读取和校验，既有审批仍绑定原目标、动作版本和参数；不会自动执行或增加授权。本次不增加数据库字段，无需新迁移。

## 升级与回退

更新后端和前端构建并重新启动 API、AI worker 与使用相同网关的 report-worker。新配置与旧排队任务不一致时，任务以 `configuration_changed` 结束，由人工重新发起；不自动重试模型调用。先检查是否有活动任务再安排重启，不升级或改写业务数据库。

回退前停止新增诊断和回放，保存当前代码与运行记录；恢复旧代码后重启相关组件。新增加的配置键和 JSON 轨迹无需数据库降级；回退会恢复旧版能力约束，不能作为继续保持本次只读限制的方式。

## 验证范围

组合测试覆盖服务指标取证、候选提交、跨轮继承、人工采用、Admin 预览及哈希冲突、冻结回放、无关监测拒绝、私有数据不发布、只读工具/结果拒绝及历史提案兼容。测试使用显式独立 `sentinelops_design_regression_test`；前端检查案例预览及原页面加载、类型和生产构建。真实付费模型、外部邮件和远程资源不属于本次验证。

2026-10-23 完整后端回归：791 通过、30 跳过、两项主动排除。排除项为此前已确认受 Windows Schannel 影响的 HTTPS Git 公共/私有同步用例，本次未重测；不记为通过。新增四项组合及边界测试通过，原真实 Harness SDK/MCP 与本地模拟 Provider、会话、审批执行和报告回归均通过。

前端 134 项测试通过，类型检查和生产构建通过；Docker 启动时首次出现的两项页面加载超时在环境稳定后按原测试阈值重跑通过。OpenAPI 与生成类型同步，Ruff 检查通过，无需新增数据库迁移。

浏览器使用隔离账号实际验证预览前不能保存、读取冻结记录后重置确认、确认脱敏并保存版本、发起模拟基线回放，最终结构和引用均通过。截图位于本机 `.local/design-completion/agent-fix-preview.png`、`agent-fix-evaluation.png`。该浏览器流程使用已有正式诊断；服务监测跨轮到采用和回放的组合流程由固定模型驱动的数据库集成测试覆盖，不将其写成真实付费模型效果。
