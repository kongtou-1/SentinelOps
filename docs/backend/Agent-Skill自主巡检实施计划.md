# Agent Skill 自主巡检实施计划

## 目标

新增自主巡检模式：Agent 读取 Skill，根据业务参数调用授权 API，筛选列表，逐项读取详情，在隔离 Python 环境处理和校验数据，保存每个项目的结论与证据。保留原有采集后逐条检查模式。

## 实施范围

1. 计划增加巡检模式、授权 API 数据源集合及 JSON 业务参数。Skill 增加版本化 Python 脚本，支持临时生成代码。
2. Agent 工具增加授权 API 列举、动态 API 请求、隔离 Python 执行。接口地址、HTTP 方法、路径模板及允许的动态参数由管理员配置；凭据仍加密保存，不交给模型或 Python。
3. Python 执行交给专用沙箱服务。服务仅接受固定执行协议，不接受 Docker 参数；创建无网络、无宿主机挂载、非 root、只读根目录且限制 CPU/内存/进程/时间/输出的临时容器。Docker socket 只交给可信沙箱服务，不交给业务 worker 或生成的代码。
4. 自主模式以一轮 Agent 会话组织任务，不预先扫描业务列表。工具结果先保存为脱敏证据；Agent 返回逐项目结果，平台验证证据引用后生成现有巡检记录。未完成、预算不足与无匹配项目应明确记录，不能当作全量通过。
5. 前端提供模式、授权 API、业务参数、接口调用范围及 Skill 脚本编辑；自主模式隐藏不适用的字段关联和逐条规则配置。不增加解释性小字。

## 执行边界

- API 仅限计划绑定且版本未变化的数据源。每次外部操作前后核验计划、Skill、用户授权及数据源；禁止由返回数据指定新主机、任意请求头或凭据。
- POST 只允许管理员明确标记为查询用途的固定接口；不提供修改业务数据、SSH 或修复动作工具。
- Python 只能处理传入的脱敏数据和临时文件；无法联网、访问业务库、平台文件或业务凭据。允许标准库，不运行自动安装依赖。
- 对调用数、响应大小、运行时间和项目数设置限制；保留请求参数、脚本摘要、执行输出及来源引用。
- 本次完成源码、本地隔离测试与部署接入说明。没有用户实际 API，不声称完成真实业务联调。

## 验证顺序

1. 数据结构与迁移、OpenAPI 及前端生成类型。
2. 独立 `_test` 数据库验证：兼容旧计划；列表标记筛选、多个详情与逐项入库；凭据脱敏、越权接口、路径绕过、授权撤销、证据伪造和预算耗尽。
3. 真实临时容器验证：Python 运算、Skill 脚本、无网络、非 root、只读目录、超时/输出限制及容器清理。
4. 相关后端回归、前端检查与生产构建；记录结果和真实联调限制。
