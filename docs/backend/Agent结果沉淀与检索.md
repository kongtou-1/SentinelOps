# Agent 结果沉淀与检索

诊断、巡检沿用已有业务记录保存结果，检索层仅投影现有记录，不另建重复的证据档案表。本次无数据库迁移。

## 归属与页面入口

| 类型 | 保存位置 | 页面入口 |
| --- | --- | --- |
| 正式事故诊断 | `agent_analyses`，关联事故 | 诊断工作台顶部「结果档案」 |
| 私有诊断对话 | `analysis_runs/messages/events`，关联会话和事故 | 同一档案内按当前会话访问 |
| 巡检对象结果 | `inspection_items`，关联计划和批次 | 任务详情、批次报告「Agent 结果」 |
| 独立 Agent 检查 | `inspection_check_results/traces` | 同上，按对象与检查项定位 |
| 人工提炼知识 | `knowledge_documents/chunks` | 结果详情「提炼为知识」→知识详情 |

业务执行历史继续保留失败、中断、取消等状态。复用检索展示已完成结果和已完成对话；执行完成不等于结论已确认、问题已解决或知识已审核。

诊断结果按当前事故检索，私有对话还须指定并通过会话访问检查；巡检按当前计划检索，可再限定批次。运行工具不能读取其他事故、计划或其他会话。巡检历史检索排除当前批次，跨事故、跨任务复用通过审核启用的知识完成。

## Agent 如何查找

两个 Agent 的系统提示均说明以下工具，启动时自动提供最近三条摘要目录：

- `search_agent_history`：在当前业务范围按关键词检索结果正文、对象、检查项；诊断会话还可检索历史消息。默认 3 条、最多 10 条，使用 `offset` 翻页，返回摘要最多 500 字符。
- `read_agent_history`：传入 `kind/result_id`，分段读取 `result`、`evidence`、`configuration`；私有对话还可读 `messages`。默认每段 4,000 字符、最多 8,000 字符，通过 `next_offset` 继续读取。
- `search_knowledge`：检索当前服务及适用版本内已启用、未过期且索引就绪的知识。巡检也接入此工具，每次最多 3 个片段。

历史结果包含来源 ID、所属业务、时间和 `historical=true`。原始证据不随目录加载。历史检索本身不是新的运行观测，不能用历史工具的返回 ID 冒充本轮证据；巡检的历史和知识工具不进入本轮可引用证据集合。

## 上下文预算

预算采用字符数，不声称等同于模型 token 数或覆盖所有模型容量。原始记录不会被这些投影截断。

| 内容 | 限制 |
| --- | --- |
| 自动加载的历史轮次 | 最近 8 轮 |
| 自动加载的对话 | 最近 12 条；总计最多约 12,000 字符，单条最多 3,000 |
| 带入新轮次的原始证据 | 最多 30 条、约 128,000 字符；优先保留上轮候选结论引用的记录 |
| 初始提示中的历史证据 | 只放目录，最多约 8,000 字符，含原轮次定位引用 |
| 历史知识片段 | 最多 10 条、约 16,000 字符 |
| 上轮候选诊断 | 最多约 6,000 字符；过长时明确标记截取 |

较早的用户约束、结果及证据仍可搜索、分段读取。新轮次不再无上限复制历史证据和知识。当前轮次已有工具次数、证据大小、超时和模型请求限制继续生效；这不表示任意长的单轮原始输入都能适配任意模型。

## 知识审核

有 `knowledge:manage` 权限的用户可编辑提炼正文并保存草稿。草稿默认停用，保留 `agent-result:<kind>:<id>` 来源和服务适用范围，同一来源重复操作返回已有知识，来源字段不可改写。无结构化诊断的普通对话不能直接转为知识草稿。

知识详情显示「待审核草稿」「查看来源结果」「审核并启用」。显式启用时再次检查来源可访问、仍有效，并记录审核操作；之后进入既有版本化索引流程。停用、过期、删除或索引未就绪的内容不进入 Agent 检索。不会自动发送邮件、修改 Skill 或生成执行授权。

## API 与部署

接口以 `/api/v1` 为前缀：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/agent-results?business=diagnosis|inspection&scope_id=<id>` | 摘要分页；可选 `query/conversation_id/run_id/offset/limit` |
| GET | `/agent-results/{kind}/{id}` | 按 `section/offset/limit` 读取一段原文 |
| POST | `/agent-results/{kind}/{id}/knowledge-draft` | 显式保存停用草稿，另需业务读取和知识管理权限 |

重建本机已有 backend、frontend 镜像并沿用现有 Compose 覆盖文件启动。无需修改数据库、远程目标、模型密钥或沙箱权限。历史数据直接可检索，历史巡检缺失的模型配置不补写；新执行保存模型配置快照，真实通道用量继续由既有用量记录追踪。
