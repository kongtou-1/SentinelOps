# 独立看护

要求 Python 3.11 以上，仅使用标准库。复制 `config.example.json` 到运维机器的私有目录，配置明确收件人及 SMTP，并将 `enabled` 设为 true 后运行：

```powershell
python deployment/watchdog/watchdog.py --config .local/watchdog/config.json --once
python deployment/watchdog/watchdog.py --config .local/watchdog/config.json
```

可交给 Windows 任务计划或 systemd 启动第二条命令。推荐部署在另一台机器，通过受控网络访问平台和监控组件；不要为看护开放数据库或 Docker socket。HTTP 检查不使用平台账号或数据库，API/数据库停止仍能直接投递 SMTP。认证 SMTP 必须开启 TLS，密码只从独立文件读取。

状态文件保存于配置旁的 `*.state.json`。相同故障只尝试通知一次；观测恢复后再次故障会产生新通知。SMTP DATA 结果不明确时记为 unknown，不自动重复发送；人工核对投递结果后可移走状态文件重试。未启用时仅检查；启用后先移走先前的试运行状态文件，再执行一次检查。配置、密码和状态文件不提交仓库。

本机隔离 Mailpit 可将 SMTP 端口设为实际映射端口。远程部署和外部 SMTP 必须单独实测。本轮交付包含脚本及本地故障通知验收，不代表另一台机器已经部署。
