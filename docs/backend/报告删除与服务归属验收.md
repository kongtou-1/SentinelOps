# 报告删除与服务归属（2026-10-15）

- Admin 可在报告列表和详情软删除报告；Viewer/Operator 请求删除返回 403。生成中或邮件派发中的报告返回 409。
- 删除后全局列表、事故报告历史、详情、修订、导出及发送记录接口不再提供该报告；数据库保留冻结证据、修订、发送历史，并追加审计及事故时间线。
- 报告直接关联事故；涉及服务从冻结告警目标、审批/执行容器、源码版本关联及修复交接追溯。支持多个服务，主机告警不自动归属于同机业务。
- 新报告冻结服务及资源名称。历史报告通过已有目标与现有资产关联展示，标明来源，不改写原始快照或摘要。
