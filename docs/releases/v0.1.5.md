# SentinelOps v0.1.5

## 中文

首次 GitHub 发布，包含 SentinelOps 平台源码和从当前源码重新构建的 Windows x64 桌面客户端。桌面端复用 Web 业务页面，连接独立部署的 SentinelOps 后台，不包含原机器的配置、账号、业务数据或模型密钥。

### 本版内容

- 统一资源监控、趋势预测、告警与事故、诊断 Agent、巡检 Agent、问数 Agent、复盘和系统管理工作台。
- 智能问数基于 NVIDIA Auto-Ontology 适配扩展，增加代码仓库快照、Python / Java 规则抽取、源码出处关联及平台授权校验。
- 同步当前巡检任务、运行轨迹、问数目录与设置页面。
- 提供中英文 README 和项目截图；保留上游来源、补丁记录及第三方许可证。

### 下载与使用

| 附件 | 用途 |
| --- | --- |
| `SentinelOps-0.1.5-x64-setup.exe` | Windows x64 安装包 |
| `SentinelOps-0.1.5-win-x64.zip` | 完整免安装目录；解压后运行其中的 `SentinelOps.exe`，不要只复制 EXE |
| `SHA256SUMS.txt` | 安装包、ZIP 和发布清单的 SHA-256 校验值 |
| `release-manifest.json` | 源码提交、构建组件、附件摘要与验证记录 |

先部署相同版本源码对应的后台，再在桌面端填写服务根地址，例如 `https://ops.example.com`，测试连接并使用后台账号登录。地址不要附加 `/api/v1`。后台部署步骤见仓库 README。

### 实际验证

- 前端 318 项测试通过；前端类型检查与桌面生产构建通过。
- 桌面网络及专用 `_test` 后台联调 7 项通过，包含登录、三种角色权限、令牌刷新与认证 SSE。
- 最终打包 EXE 原生冒烟 7 项通过，包含服务器配置、导航、刷新、SSE、内置页面与服务器切换。
- ASAR 内 134 个桌面源码及前端构建文件逐字节一致，项目与运行时许可证检查通过；NSIS 安装包归档完整性检查通过。
- 本机为 Windows 10 x64。工作区继承的 Low 完整性标签曾导致原生运行时启动失败；同一程序在普通临时目录通过验收，最终包在普通临时目录构建，没有关闭沙箱或修改系统安全设置。

### 已知限制

- 安装包未配置发行签名，Windows 可能显示未知发布者。
- 未覆盖已有安装的完整升级/卸载流程，也未单独验证 Windows 11。
- 桌面验收使用隔离数据与真实 FastAPI，不代表真实模型质量、业务诊断准确率或大规模问数验收。

## English

First GitHub release of the SentinelOps platform source and a Windows x64 desktop client rebuilt from the current source. The client shares the web UI and connects to a separately deployed server. Machine-specific configuration, accounts, business data, and model keys are excluded.

### Included

- Monitoring, forecasting, alerts and incidents, diagnosis, inspections, natural-language querying, postmortems, and administration.
- Auto-Ontology-based querying extended with repository snapshots, static Python / Java rule extraction, source provenance, and platform authorization.
- Current inspection trajectories, query catalog and settings, bilingual READMEs, screenshots, upstream provenance, and license materials.

Use the installer or extract the complete standalone ZIP and launch `SentinelOps.exe`. Deploy the matching server first, enter its root URL, test the connection, and sign in. Do not append `/api/v1`. `SHA256SUMS.txt` and `release-manifest.json` provide checksums and source/build provenance.

### Validation and limits

318 frontend tests, type checking, and the desktop production build passed. Seven network/backend integration checks and seven native desktop smoke checks passed against an isolated `_test` database. All 134 packaged desktop source/UI files matched their inputs; license and NSIS archive integrity checks passed.

Validation ran on Windows 10 x64 from a normal temporary directory. Inherited Low integrity labels in the workspace affected native runtime startup; the identical binary passed outside that directory. Sandbox and system security settings were preserved.

The installer is unsigned. Existing-install upgrade/uninstall flows and Windows 11 were not separately validated. These checks do not establish model quality or production business accuracy.
