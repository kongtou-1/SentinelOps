# SentinelOps v2 前端改版

设计依据：`docs/SentinelOps v2 · Beszel 风格设计稿.pptx` 的 6 页。采用深色背景、顶部图标导航、细边框卡片、紧凑表格，以及蓝 / 绿 / 橙 / 粉红的图表与状态配色。原设计稿保留。

| 设计页 | 网页对应 | 数据与操作 |
| --- | --- | --- |
| 总览 | `/` | 巡检全局统计、近七天新增告警分布、即时服务器状态、待审批、资源趋势、事故和预测入口 |
| 资源中心 | `/servers`、`/containers`、`/llm-endpoints` | 全局资源摘要、当前页资源选择、三列实测趋势；服务器显示 CPU / 内存 / 磁盘条形指标；原表单、SSH 测试、探测和同步入口保留 |
| 预测中心 | `/predictions`、`/predictions/:id`、`/prediction-tasks` | 使用现有 MSTL + AutoETS 和 1h / 6h / 24h 结果，展示实测、预测、风险及预测卡片 |
| 告警与事件 | `/incidents`、`/alerts`、`/alert-rules` | 事故按待处理 / 处理中 / 已恢复 / 已闭环分列；看板与列表可切换，筛选和分页保留 |
| AI 决策与审批 | `/approvals`、`/approvals/:id`、`/executions` | 三栏展示审批绑定版本的诊断、队列和授权核对；审批与执行仍在详情页按原流程进行 |
| 复盘报告 | `/reports`、`/reports/:id` | 冻结事实摘要、时间线、原因与恢复、经验及改进建议；原版本历史、编辑、审核、证据、PDF / Word 和人工邮件入口保留 |

知识库、Skill、动作目录、用户、角色、凭据、审计、系统状态及连续诊断工作台沿用相同组件风格。顶部导航按原有权限显示，`Ctrl K` 可搜索有权限访问的页面，“接入资源”打开已有服务器新增表单。

## 占位与事实边界

综合健康评分、全量离线资源汇总、手动新建事件、SLA / 批量派单、模型特征贡献、诊断置信度、双人复核、审计导出、5 Why 专项分析和改进任务跟进显示“待接入”。设计稿中的产线、阀门、XGBoost、自动执行和示例数字没有作为平台事实使用。

看板统计限定当前筛选页，保持原分页；总览资源表显示最近创建的最多五台服务器。资源趋势选择范围为当前列表页，图表每 30 秒刷新。没有采样时保留空值；采集状态来自 Prometheus `target_up`，不能用“启用监控”推断在线。失效预测明确显示数据过期，缺少预测点时说明图中只有历史实测。

审批工作台按审批详情中的 `analysis_id` 读取对应诊断；重新诊断不会替换正在查看的授权依据。执行保持 Admin 审批、Operator / Admin 人工发起、固定 `restart_container v1`、前置检查和恢复验证。复盘基于冻结快照；资源核验计数与报告审核状态分开显示。
