# 项目介绍页面

入口：主工作台右上角「项目介绍 ↗」，地址为 `http://127.0.0.1:8080/project-intro`。

## 页面与访问

- 使用现有 Vue 3，按路由加载独立页面。沿用登录校验及 `resources:read`，Viewer、Operator、Admin 均可阅读。
- 普通点击在新标签页打开，沿用资源中心的新标签页处理：继承当前会话后清除 opener，原工作台保留。直接访问未登录地址时，登录后返回介绍页。
- 十个章节采用浅色横版汇报布局，顶部目录可跳转并随阅读位置高亮；手机端将多列图示排为纵向。
- 每页只保留大标题与主体内容，页标题不设英文页眉与标题下说明小字；大标题以章节名开头（如「现状：团队运维，需要跟上项目增长」），标题左侧有短竖线标识，图表自带标签。第一页两张面板内部各带「序号 + 英文栏目名 + 中文栏目名」的小标签。SVG 和 HTML/CSS 绘制结构与关系图，无生成图片、外部字体或新增依赖。截图可点击放大，关闭按钮、Esc 和遮罩可关闭预览。
- 第一、二页底部采用浅蓝、左对齐的结论条，第二页保留叠层图标；十页结论条均只保留结论句与右下角页码，不再放置「直接价值」「关键矛盾」这类小标签。
- 页面不读取业务统计、不轮询、不写入业务记录。
- 顶部目录右侧「演示」按钮进入全屏汇报模式：一屏只显示一页，白色页面铺满整个视口，十页内容共用同一画布高度并按视口等比缩放居中，短页的主图区自动撑开填满页面。进入时定位到当前阅读章节，退出后回到该章节。翻页支持 `←`/`→`/`↑`/`↓`/`PageUp`/`PageDown`/空格/回车、滚轮（520ms 节流）、`Home`/`End`、底部工具条的上一页／下一页／章节圆点；`Esc` 退出。工具条显示章节名、页码与顶部进度条。图片预览在演示模式下仍可打开，首次 `Esc` 只关闭预览、不退出演示。浏览器拒绝全屏时降级为覆盖层演示，不影响翻页。
