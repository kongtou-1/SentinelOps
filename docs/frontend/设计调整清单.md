# 27 页设计调整清单

页面内容依据 `docs/运维平台总览首页.pptx` 与实际后端能力。2026-10-04 按用户提供的新参考图调整为白色侧栏、淡灰紫工作区、紫色主色、细边框圆角卡片与浅色状态标签；统一列表、详情、表单和登录页风格。原 PPT 未修改。

菜单采用一级入口与可折叠二级分组：总览、事故中心、复盘报告直接进入页面；资源、预测、告警、审批与执行、知识与 Skill、系统管理点击展开或收起。当前页面所属分组自动展开，详情页高亮所属列表；权限过滤仍由现有账号权限决定。顶部按钮可收起整个侧栏，手机和平板默认收起，进入页面或点击遮罩关闭。

总览卡片展示真实数量与状态，告警以严重程度色条、名称、资源、时间、确认状态和触发状态组成列表。参考图中的搜索框、增长百分比与卡片趋势线没有对应接口或历史数据支持，本次不添加；资源趋势保留实际 Prometheus 数据。

| PPT 页 | 网页入口 | 落实内容与调整 |
| --- | --- | --- |
| 1 总览 | `/` | 真实资源/告警/事故数量、有效待审批；趋势选择单台服务器及单指标，LLM 停用/未知单独显示 |
| 2 事故详情 | `/incidents/:id` | 事故概况、时间线、负责人、诊断证据、提案、审批执行和复盘关联 |
| 3 登录 | `/login` | 用户名登录；取消邮箱账号、剩余锁定次数和未实现的密码找回 |
| 4 服务器列表 | `/servers` | 名称/地址搜索、分页、新增编辑、SSH 测试；资产配置与详情指标分开 |
| 5 服务器详情 | `/servers/:id` | CPU、内存、分区最高磁盘使用率、HTTP 指标、趋势、容器及关联事件；缺失注明原因 |
| 6 容器列表 | `/containers` | 名称/镜像搜索、服务器筛选、显式同步；清单状态标明来自最近同步 |
| 7 LLM 列表 | `/llm-endpoints` | 服务/模型搜索、真实探测状态、配置表单、显式探测及停用 |
| 8 容器详情 | `/containers/:id` | CPU/内存/重启/OOM、历史网络指标、所属服务器；删去没有接口依据的启动命令、端口映射 |
| 9 LLM 详情 | `/llm-endpoints/:id` | 近 30 分钟主动探测成功率、次数与 30 秒分格状态条；5 分钟窗口均值/P95、错误分类；不宣称真实业务流量或 24h SLA |
| 10 事故列表 | `/incidents` | 后端 open/in_progress/recovered/closed/merged 枚举、严重程度、未分配、资源与时间过滤 |
| 11 预测结果 | `/predictions`、`/predictions/:id` | 1h/6h/24h 曲线、95% 区间、异常点、实际模型、质量和过期说明；不混合不同指标单位 |
| 12 预测任务 | `/prediction-tasks`、`/prediction-tasks/:id` | 新增编辑、启停、手动运行、历史结果；没有模型任选，分区/网卡选择来自实际采样 |
| 13 告警列表 | `/alerts` | 级别、触发状态、人工确认、资源和时间过滤；取消无接口依据的批量确认与导出 |
| 14 告警详情 | `/alerts/:id` | 单条确认及说明；触发/确认/恢复核验分别显示，待核验不显示为待审批 |
| 15 规则 | `/alert-rules` | 新增编辑、启停、目标和阈值；保存之后由 Admin 单独显式应用 |
| 16 审批列表 | `/approvals` | 全局分页摘要、状态/事故/发起人/时间；过期审批不计待办 |
| 17 审批详情 | `/approvals/:id` | 仅 restart_container v1，冻结绑定只读，Admin 决定；批准后 Operator/Admin 单独发起执行 |
| 18 执行详情 | `/executions`、`/executions/:id` | 独立执行列表、阶段、前置检查、输出和恢复验证，终态与审计来自执行记录 |
| 19 复盘列表 | `/reports` | 全局分页、人工选择已关闭事故生成、状态/事故/发起人/时间过滤 |
| 20 复盘详情 | `/reports/:id` | Admin 编辑与审核，乐观版本校验、证据引用、版本及投递记录；批准后才开放导出和显式发送 |
| 21 知识库 | `/knowledge`、`/knowledge/:id` | Markdown 维护、标签、向量检索、索引状态；不伪造全文检索/知识分类接口 |
| 22 诊断 Skill | `/skills`、`/skills/:id` | 管理 agent Skill 的适用场景、步骤、输出要求、版本及启用状态；agent 按需加载，不伪造调用次数和未支持的工具开关 |
| 23 动作目录 | `/action-skills` | 只读展示后端固定 restart_container v1 参数、风险和约束，不开放任意命令编辑 |
| 24 用户权限 | `/users`、`/roles` | 用户名、固定角色、启停、必要表单；角色说明来自实际权限，不创建自定义角色 |
| 25 SSH 凭据 | `/ssh-credentials` | 新增/替换/软删除、加密保存；取消不存在的凭据到期信息，不返回私钥或密码 |
| 26 审计 | `/audit-logs` | 事故/审批/执行/报告/操作人、动作与时间过滤及详情；取消未实现的 CSV 导出 |
| 27 系统状态 | `/system` | 实际 API 存活、数据库与迁移就绪检查；删除 Celery、业务积压、虚构连接数/延迟和 SLA |

必要的新增/编辑表单以弹窗提供：服务器、LLM 配置、预测任务、告警规则、知识文档、Skill、用户和 SSH 凭据。容器通过同步获得，不提供创建真实容器的表单。事故分配、备注、合并、审批意见、报告审核和发送有独立输入与状态校验。

1280、1440、1920 使用固定侧栏和自适应工作区；1024 以下切换折叠菜单。窄屏表格保留内部横向滚动，详情和表单纵向排列。没有后端依据的筛选、数据和导出入口不展示。
