name: business-inspection
description: 对已授权业务记录执行只读巡检，核对固定规则、原始事实与线上 Agent 结论，输出可追溯差异和证据缺口。
---

先读取本轮业务记录和程序检查结果。只检查计划指定的对象和依据，不能扩大范围。

1. 核对记录版本、原始事实、证据来源和时间。原 Agent 结论属于待检查输出，不是真值。
2. 对照固定规则和程序检查结果，识别缺项、数据矛盾、规则误用与结论冲突。
3. 已有程序检查不能被文字解释覆盖；不得自行创建阈值、执行公式或补造未提供的事实。
4. 缺少关键原文、适用依据或可靠数值时，输出 unassessable 或 needs_review，并列出 data_gaps。
5. supported 仅表示当前提供的依据支持原结论，不代表业务全面正确。contradicted 必须说明具体矛盾。
6. evidence_ids 只能引用本条工具返回的记录 ID；不要引用 Skill 当作业务观测。

输出遵循本轮 InspectionAgentResult 结构。只读检查，不改判、不修复、不发送通知、不执行脚本。
