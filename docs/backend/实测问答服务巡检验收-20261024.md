# 实测问答服务巡检验收

2026-10-24，本机 `sentinelops` 部署。服务：`实测问答服务`，ID 为 `9501216c-a795-4220-b06e-69ab00fe5ac2`，环境 `local-test`。

## 接入方式

现有服务没有历史问答记录查询接口。本次实际 GET `/status`、`/health`、`/ready`、`/work`，将采样响应保存到本机快照，再通过固定 GET 接口供巡检读取。仅验证工作请求的响应契约，不能证明问答答案正确。

- 适配器：[inspection_source.py](../../testlab/inspection_source.py)，只读取快照，不向业务转发写请求。
- 独立 Compose：[compose.inspections.yaml](../../testlab/compose.inspections.yaml)，与平台共用网络，代码和快照均只读挂载，不开放宿主机端口。
- `/records` 提供真实响应快照；`/acceptance-records` 提供明确标注的三个回放控制样例。回放没有向真实服务注入故障。
- 时间窗口使用真实采样时间，起点包含、终点排除；支持受限分页和游标。
- 只有一条记录进行真实 Agent 评审；回放计划每 60 秒自动运行，用于检查去重。测试结束及异常退出时均暂停本次计划。
