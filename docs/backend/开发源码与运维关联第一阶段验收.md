日期：2026-10-13。

## 实现范围

完成服务登记、Git HTTPS 公私有仓库与只读本地目录、异步源码快照、只读文件浏览/搜索/差异、运行路径映射、发布登记、实际容器/LLM Endpoint 部署历史及 Docker 身份采集。入口为“资源中心 → 应用与服务”。使用说明见[第一阶段文档](开发源码与运维关联第一阶段.md)。

同一镜像对应不同入口的服务分别登记；相同来源可显式复用快照。发布与部署保存当时的源码、入口、路径映射和镜像核对依据。镜像身份一致与构建源码已确认分别显示，本地目录只作为参考源码。没有源码仍可登记发布；Git、目录或 worker 不可用不阻塞核心 API。
