1. 读取本条证据和程序结果，核对证书版本、仪器型号/编号、项目、量程、档位和点位。
2. 核对内页原文片段、表格定位及关键数值是否齐全。只有原 Agent 识别表格、没有原文时，明确保留识别错误风险。
3. 检查规程/规范、客户要求、判定规则的来源与版本。不得只凭规程名称猜测限值，不默认全部取最严，也不自行选择不确定度保护带。
4. 对照注册检查器的数值、单位和覆盖检查结果，说明原线上结论的差异；不在语言模型中替代确定性复算。
5. 校准数据、证书完整性及满足客户用途分别核对。缺少适用条件、原文、规则或可靠数值，输出无法评估或待复核。
6. 明确区分疑似误拒、疑似漏检与证据不足。没有重新测量，不宣称已知道仪器真值。
