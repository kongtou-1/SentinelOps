# 页面标题关键指标

2026-10-30 最新调整：按用户要求，已移除所有页面标题区的指标卡及接入，不再加载标题统计。标题字号改为 20px（窄屏 18px），标题卡片最小高度改为 64px。以下内容保留为历史实现与验收记录。

主控制台的业务列表、详情与巡检任务编辑页，在标题区域展示当前业务的 2～4 个关键值。使用 `PageMetrics` 统一布局，宽屏标题与紧凑指标卡放在左侧，操作按钮单独靠最右侧；窄屏指标换行，操作仍靠右。

按用户提供的参考图使用带轻渐变底色和细边框的独立指标卡，不放说明小字、信息图标或 logo。卡片标准宽度 168px、最小高度 84px，指标名称保持 16px，数值为 26px；与标题间距 24px。总量采用蓝色，可用／运行采用绿色，失败／停止采用红色，待处理／缺口采用琥珀色。颜色按指标含义固定，不把正常零值变成未知数据。宽屏验收使用完整页面视口。

| 执行动作目录 | 动作数量、需管理员审批的动作数量 |

详情页展示当前对象的数据：资源使用率与延迟、巡检检查项及对象预算、事故关联告警与恢复确认、预测阈值与数据缺口、报告修订与冻结证据、知识版本与适用范围。新建／编辑巡检任务的指标随表单草稿更新。

## 数据与刷新

- 列表统计独立于当前分页。库存和配置类数据读取完整分页；告警、事故、审批、执行及报告使用既有筛选接口的 `X-Total-Count`，每次只请求一条数据。执行各阶段分别统计后相加。
- 标题默认展示该页面的全部可见记录；服务巡检、指定任务执行记录及指定报告整改保留路由范围，不跟随表格的临时搜索和状态筛选。
- 页面数据刷新后刷新标题统计，窗口重新激活时重新读取；HTTP 连接保存与刷新后同步更新指标。未新增独立的高频轮询。
- 未取得数据、请求失败和缺少总量时展示“—”。真实零保持为 0。过期或未知 LLM 探测不计入可用，预测最新结果必须完成且有效。
- 复用原有接口权限；无权读取报告投递数据时不展示投递数量。仅修改前端，没有调整数据库、审批或执行权限。
